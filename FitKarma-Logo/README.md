# FitKarma Logo Pack v1.0

This package contains the approved FitKarma running-figure direction, prepared as practical starter assets.

## Core identity
- Brand: FitKarma
- Positioning: India’s AI-powered Fitness and Wellness Ecosystem
- Primary green: #16A34A
- Accent lime: #A3E635 / #65C94B
- Premium gold: #D6A84B
- Deep dark: #0D0F12
- Light: #F8FAFC

## Files
- `svg/fitkarma-primary-dark.svg` — horizontal logo for dark backgrounds, with positioning line.
- `svg/fitkarma-primary-light.svg` — horizontal logo for light backgrounds, with positioning line.
- `svg/fitkarma-wordmark-dark.svg` and `...-light.svg` — compact wordmarks without tagline.
- `svg/fitkarma-mark.svg` — standalone transparent symbol.
- `svg/fitkarma-app-icon-dark.svg` and `...-light.svg` — app-icon backgrounds.
- `svg/fitkarma-monochrome-*.svg` and mark monochrome files — one-colour use.
- `png/` — corresponding raster exports.
- `preview/approved-logo-system-reference.png` — approved generated logo sheet for visual reference.

## Usage notes
Use SVG for websites, print and scalable layouts. Use PNG for apps and tools that require raster images. The transparent logo files are not intended to be placed on backgrounds with insufficient contrast.

The SVGs use text elements with common sans-serif fallbacks; for final trademark/print artwork, convert wordmark text to vector outlines in a design application and have the final mark reviewed for distinctiveness and trademark availability. These assets are a visual identity draft, not legal clearance.
