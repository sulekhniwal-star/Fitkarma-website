# Plan 02-03: Navigation Shell (Header, Footer) & Component Showcase Verification

## Objective
Implement the global `Header` and `Footer` layout components featuring the official vector brand logo, bilingual language switcher, and Indian craft aesthetics, update the landing preview with a live component showcase, and verify quality gates.

## Tasks

### Task 1: Build Global Header (`src/components/layout/header.tsx`)
- Sticky frosted glass bar (`backdrop-blur-lg bg-canvas/80 border-b border-card-border/80`).
- Integrated `BrandLogo` with responsive variant (compact wordmark on mobile, full mark on desktop).
- Desktop navigation links (`Features`, `Nutrition`, `How it works`, `Privacy`, `FAQ`).
- Direct language switch toggle with native labels (`हिन्दी` / `English`).
- VIP Beta CTA button (`"Join the beta"` / `"बीटा में शामिल हों"`).
- Mobile menu drawer with accessible toggle button and focus trap.

### Task 2: Build Global Footer (`src/components/layout/footer.tsx`)
- Multi-column footer on dark obsidian canvas with subtle `JaaliPattern` background accent.
- Brand column with `BrandLogo`, positioning line, and status badge.
- Navigation link groups (Product, Trust & Privacy, Beta Programme).
- Official support contact: `sulekhniwal@gmail.com`.
- Copyright and legal version notices.

### Task 3: Assemble Landing Page Showcase (`src/app/[locale]/page.tsx`)
- Integrate `Header` and `Footer`.
- Include a live showcase section exhibiting:
  - The `PhoneMockup3D` component with interactive tilt and a preview screen.
  - Indian cultural motifs (`JaaliPattern`, `MandalaGlow`, `DesiIcons`).
  - The button variants (`primary`, `gold`, `outline`).
  - Rollout status badges (`In beta`, `Rolling out during beta`, `Planned within the beta programme`).

### Task 4: Automated Testing & Verification
- Create `tests/smoke/design-system.test.ts`:
  - Verify all approved brand SVG files exist and are readable in `public/brand/`.
  - Verify contrast ratios of text and button variants against `#0D0F12`.
  - Verify status badge labels match approved vocabulary.
- Run `pnpm type-check` and `pnpm lint`.
- Run `pnpm build` to confirm production compilation.
- Create `02-VERIFICATION.md` and update `.planning/STATE.md`.

## Acceptance Criteria
- [ ] `Header` and `Footer` render across both `/en` and `/hi` routes without hydration mismatch.
- [ ] Language toggle seamlessly switches between English and Hindi.
- [ ] `PhoneMockup3D` renders smoothly in the showcase section with visible compliance badge.
- [ ] `pnpm type-check`, `pnpm lint`, and `pnpm build` pass with zero errors.
- [ ] `02-VERIFICATION.md` generated documenting proof of compliance.
