# Plan 02-02: Atomic UI Primitives & 3D Perspective Phone Mockup

## Objective
Build reusable, accessible atomic UI primitives (`Button`, `Card`, `Badge`, `Input`) and engineer the high-performance **3D Perspective Phone Mockup** primitive with metallic chamfer edges, glass sheen, interactive tilt, and compliance badge.

## Tasks

### Task 1: Build Atomic UI Primitives
- Create `src/components/ui/button.tsx`:
  - Variants:
    - `"primary"`: High-contrast green `#65C94B` with emerald glow shadow and dark canvas text.
    - `"gold"`: Indian warm gold `#D6A84B` with brass glow shadow for founder VIP actions.
    - `"outline"`: Glass border with hover highlight and crisp white text.
    - `"ghost"`: Subdued link-style button for secondary actions.
  - Full keyboard focus indicators (`:focus-visible`).
- Create `src/components/ui/card.tsx`:
  - Translucent glass card (`bg-card/75 backdrop-blur-md border border-card-border`).
  - Subtle hover transition with soft rim illumination (`hover:border-brand-accent/40`).
- Create `src/components/ui/badge.tsx`:
  - Support approved rollout labels (`In beta`, `Rolling out during beta`, `Planned within the beta programme`).
  - Subtle glowing pill styling with distinct tinting for each status.
- Create `src/components/ui/input.tsx`:
  - Accessible label, error state, placeholder text styling, and focused ring.

### Task 2: Build 3D Perspective Phone Mockup Primitive (`src/components/ui/phone-mockup-3d.tsx`)
- Implement `PhoneMockup3D`:
  - **3D Hardware-Accelerated Chassis**:
    - Outer container with `perspective: 1200px`.
    - Sleek titanium chamfer bezel with edge rim light.
    - Glass sheen overlay simulating ambient studio lighting.
    - Dynamic Island / camera notch pill at top.
  - **Interactive Tilt / Gyro Angle**:
    - Optional gentle tilt angle (`tiltDirection="left" | "right" | "center"`).
    - Mouse movement response (calculating subtle `--rx` and `--ry` degrees on mouse enter/move).
    - Automatic flat fallback when `@media (prefers-reduced-motion)` is active.
  - **Compliance Micro-Badge**:
    - Subtly positioned below the device: *"Illustrative preview — UI subject to evolution"*.
  - **Children Slot**:
    - Flexible container inside the screen frame for rendering simulated app views (DIP feed, WhatsApp Hinglish logging, Tadka slider).

## Acceptance Criteria
- [ ] `PhoneMockup3D` renders a 3D perspective phone frame with realistic rim light and shadow depth.
- [ ] Reduced motion disables all 3D transitions and flattens orientation.
- [ ] Compliance micro-badge is permanently visible on the mockup.
- [ ] `Button`, `Card`, `Badge`, and `Input` adhere to accessibility and contrast guidelines.
- [ ] `pnpm type-check` passes with zero errors.
