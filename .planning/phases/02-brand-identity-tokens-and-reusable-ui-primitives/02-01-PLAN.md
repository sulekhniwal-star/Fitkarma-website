# Plan 02-01: Design Tokens, Indian Cultural Motifs & Brand Logo Component

## Objective
Codify the design tokens for the hybrid futuristic + cinematic Indian aesthetic, integrate the vector logo suite from `public/brand/`, and implement subtle Indian geometric SVG backdrop patterns and culinary icons.

## Tasks

### Task 1: Refine Theme Tokens & Glassmorphism Styles
- Update `tailwind.config.ts`:
  - Enhance color definitions: canvas shades (`#0D0F12`, `#12161C`, `#181D25`), brand green gradient stops (`#16A34A`, `#36C96A`, `#65C94B`), and warm Indian brass/turmeric gold (`#B98528`, `#D6A84B`, `#F4D477`).
  - Add box shadow presets: `glow-brand` and `glow-gold`.
  - Add gradient presets for glass card borders.
- Update `src/app/globals.css`:
  - Add utility classes for glass backdrop blur (`backdrop-blur-md bg-card/80 border border-card-border`).
  - Add metallic rim glow styles and perspective utility rules (`perspective-1000`).

### Task 2: Build Brand Logo Component (`src/components/ui/brand-logo.tsx`)
- Create `BrandLogo` supporting variants:
  - `"horizontal"`: Renders `fitkarma-primary-dark.svg` with running figure, wordmark, and tagline.
  - `"wordmark"`: Renders `fitkarma-wordmark-dark.svg` (compact).
  - `"mark"`: Renders `fitkarma-mark.svg` (running figure symbol only).
  - `"icon"`: Renders `fitkarma-app-icon-dark.svg` (rounded square app icon).
- Include accessible `alt` and `aria-label` tags and configurable size/class props.

### Task 3: Build Indian Cultural Motifs & Culinary Icons (`src/components/ui/indian-motifs.tsx`)
- Implement `JaaliPattern`: Pure SVG repeating pattern inspired by Indian jaali architectural fretwork, configured with low opacity (4–6%) for subtle atmospheric depth without distracting from text.
- Implement `MandalaGlow`: Radial dot-lattice SVG mandala ambient aura for section backgrounds and hero device placement.
- Implement `DesiIcons`:
  - `KatoriIcon`: Traditional Indian stainless/brass katori bowl silhouette.
  - `RotiIcon`: Stacked Indian flatbread indicator with count badge.
  - `TadkaFlameIcon`: Sizzling tempering spice and ghee flame indicator.
  - `ThaliIcon`: Rounded Indian thali plate arrangement.

## Acceptance Criteria
- [ ] `BrandLogo` renders all 4 variants cleanly without visual distortion.
- [ ] `JaaliPattern` and `MandalaGlow` render smoothly as lightweight SVGs.
- [ ] Theme tokens compile in `tailwind.config.ts` and `src/app/globals.css`.
- [ ] All colors satisfy WCAG 2.1 AA contrast requirements against `#0D0F12`.
- [ ] `pnpm type-check` passes with zero errors.
