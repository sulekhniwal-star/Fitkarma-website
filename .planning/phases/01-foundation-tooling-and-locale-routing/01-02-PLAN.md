# Plan 01-02: Subpath Locale Routing, i18n Engine & Base Layouts

## Objective
Implement Next.js middleware for bilingual path routing (`/en`, `/hi`), create English and Hindi message catalogs, and build the root and localized layouts.

## Tasks

### Task 1: Create i18n Configuration & Message Catalogs
- Create `src/i18n/config.ts`:
  - Export `LOCALES = ["en", "hi"] as const`.
  - Export `DEFAULT_LOCALE = "en"`.
  - Export `LOCALE_NAMES` mapping `en` -> English, `hi` -> हिन्दी.
  - Export `isValidLocale(locale)` guard.
- Create `src/messages/en.json`:
  - Seed with initial structured message keys: `common`, `nav`, `hero`, `features`, `registration`, `footer`.
- Create `src/messages/hi.json`:
  - Provide 100% parallel translation keys in natural, modern Hindi.
- Create `src/i18n/get-messages.ts`:
  - Export server-side helper `getMessages(locale: Locale)` returning typed dictionary with fallback to English for missing keys.
  - Export `getTranslation(locale, path)` helper for nested dot-notation access.

### Task 2: Implement Locale Routing Middleware
- Create `src/middleware.ts`:
  - Intercept incoming requests.
  - Match against `config.matcher` (excluding `api/`, `auth/`, `_next/`, `brand/`, `icons/`, `favicon.ico`, `sitemap.xml`, `robots.txt`).
  - If URL begins with valid locale (`/en` or `/hi`), attach `x-fitkarma-locale` header to response and allow request to proceed.
  - If URL lacks a locale prefix, redirect to `/${DEFAULT_LOCALE}${pathname}${search}` with 307 temporary redirect.

### Task 3: Build Root & Localized Layouts
- Create `src/app/globals.css`:
  - Tailwind directives (`@tailwind base; @tailwind components; @tailwind utilities;`).
  - Set dark background `#0D0F12` and foreground text `#FFFFFF`.
- Create `src/app/layout.tsx`:
  - Root shell layout rendering `<html>` and `<body>` without hardcoded language, serving as the shell for localized sub-layouts.
- Create `src/app/page.tsx`:
  - Root redirect forwarding to `/${DEFAULT_LOCALE}`.
- Create `src/app/not-found.tsx`:
  - Generic accessible 404 page with return link.
- Create `src/app/[locale]/layout.tsx`:
  - Validates `params.locale` against `isValidLocale()`; calls `notFound()` if invalid.
  - Renders HTML language tag attributes, fonts, and sets localized metadata.
- Create `src/app/[locale]/page.tsx`:
  - Baseline smoke test page rendering the localized title, positioning statement, and language switch link.

## Acceptance Criteria
- [ ] Direct visit to `/` redirects cleanly to `/en`.
- [ ] Direct visit to `/en` renders English smoke page with header `x-fitkarma-locale: en`.
- [ ] Direct visit to `/hi` renders Hindi smoke page with header `x-fitkarma-locale: hi`.
- [ ] Visiting an unsupported locale like `/fr` renders 404 or redirects to `/en`.
- [ ] Both `en.json` and `hi.json` exist with zero untranslated matching keys.
- [ ] `pnpm type-check` and `pnpm lint` pass with 0 errors.
