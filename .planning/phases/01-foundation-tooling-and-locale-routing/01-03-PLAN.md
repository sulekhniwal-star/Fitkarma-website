# Plan 01-03: Build Verification, Automated Smoke Checks & Quality Gate Sign-Off

## Objective
Execute automated build and lint checks, run routing smoke tests to verify bilingual resolution and environment parsing, and generate the Phase 1 verification ledger.

## Tasks

### Task 1: Create Routing Smoke Test
- Create `tests/smoke/routing.test.ts` (using Node.js built-in test runner or integration script):
  - Test `isValidLocale` against valid (`en`, `hi`) and invalid (`fr`, `de`, `null`) inputs.
  - Test `getMessages` returns required keys for both `en` and `hi`.
  - Test that all keys present in `en.json` also exist in `hi.json` (no missing translations).
  - Test `src/lib/env.ts` parses default values without throwing.

### Task 2: Execute Tooling Quality Checks
- Run `pnpm type-check` to verify complete TypeScript strictness.
- Run `pnpm lint` to verify ESLint compliance.
- Run `pnpm build` to verify Next.js static and dynamic App Router compilation.
- Run `pnpm test` (or routing test script) to verify test execution.

### Task 3: Create Phase 1 Verification Report & Update State
- Create `.planning/phases/01-foundation-tooling-and-locale-routing/01-VERIFICATION.md`:
  - Record test outputs, build timings, bundle sizes, and route manifest.
  - Document verification of requirements `ARCH-01`, `ARCH-02`, `ARCH-04`, `I18N-01`, and `I18N-02`.
- Update `.planning/STATE.md`:
  - Mark Phase 1 as Complete.
  - Advance Current Phase to Phase 2 (Brand Identity, Tokens & Reusable UI Primitives).

## Acceptance Criteria
- [ ] `pnpm build` completes successfully with valid `.next` production output.
- [ ] Automated smoke tests pass confirming dictionary symmetry between `en` and `hi`.
- [ ] Zero TypeScript or ESLint warnings/errors.
- [ ] `01-VERIFICATION.md` created with documented proof of compliance.
- [ ] `.planning/STATE.md` updated with Phase 1 marked complete.
