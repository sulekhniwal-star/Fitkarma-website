# Plan 01-01: Project Scaffold, Tooling, Environment Schema & Dependencies

## Objective
Establish the Next.js App Router codebase, configure TypeScript, Tailwind CSS, ESLint, and implement strict environment variable schema validation via Zod.

## Tasks

### Task 1: Initialize Base Project Configuration & Manifests
- Create `package.json` with scripts:
  - `"dev": "next dev"`
  - `"build": "next build"`
  - `"start": "next start"`
  - `"lint": "next lint"`
  - `"type-check": "tsc --noEmit"`
  - `"test": "node --test --import tsx tests/integration/*.test.ts"`
- Include runtime dependencies (`next`, `react`, `react-dom`, `@supabase/supabase-js`, `resend`, `zod`, `clsx`, `tailwind-merge`, `lucide-react`).
- Include dev dependencies (`typescript`, `@types/node`, `@types/react`, `@types/react-dom`, `tailwindcss`, `postcss`, `autoprefixer`, `eslint`, `eslint-config-next`, `tsx`).
- Create `tsconfig.json` with strict type checking, path aliases (`@/*` pointing to `./src/*`), and Next.js plugin integration.
- Create `.gitignore` ignoring `.next/`, `node_modules/`, `.env*.local`, `dist/`, and coverage artifacts.

### Task 2: Configure Styling & Build Pipeline
- Create `tailwind.config.ts` configured with content paths (`./src/**/*.{js,ts,jsx,tsx,mdx}`), dark mode preference, and placeholder brand color palette matching `04_DESIGN_SYSTEM.md`.
- Create `postcss.config.mjs` with `tailwindcss` and `autoprefixer`.
- Create `.eslintrc.json` extending `next/core-web-vitals`.

### Task 3: Implement Zod Environment Variable Validation
- Create `.env.example` documenting all required and optional environment variables with clean dummy placeholders (no real secrets).
- Create `src/lib/env.ts` with Zod schema parsing:
  - `NEXT_PUBLIC_APP_URL`: string url, default `http://localhost:3000`.
  - `NEXT_PUBLIC_SUPABASE_URL`: string url.
  - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: string min 1.
  - `SUPABASE_SERVICE_ROLE_KEY`: string min 1 (optional in dev if mocks used).
  - `RESEND_API_KEY`: string (optional if dev sink enabled).
  - `EMAIL_DEV_SINK`: boolean, default `true` in development.
  - `ADMIN_EMAIL_ALLOWLIST`: string list / comma-separated.
  - `BETA_REGISTRATION_PAUSED`: boolean, default `false`.
- Ensure helpful error formatting if a required environment variable is missing at startup.

### Task 4: Install Dependencies & Verify
- Run `pnpm install` (using rule: BypassSandbox for pnpm install on Windows).
- Run `pnpm type-check` to verify TypeScript compiler passes on baseline files.

## Acceptance Criteria
- [ ] `package.json`, `tsconfig.json`, `tailwind.config.ts`, `postcss.config.mjs`, and `.eslintrc.json` exist and are valid.
- [ ] `pnpm install` resolves dependencies cleanly with lockfile created.
- [ ] `.env.example` contains all environment keys with no real secrets.
- [ ] `src/lib/env.ts` exports a typed `env` object that parses without crashing in development mode.
- [ ] `pnpm type-check` runs without compilation errors.
