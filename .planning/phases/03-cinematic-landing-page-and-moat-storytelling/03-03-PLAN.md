# Plan 03-03: Homepage Integration, SEO Metadata & Quality Verification

## Objective
Assemble all marketing sections into a cohesive, high-converting homepage in `src/app/[locale]/page.tsx`, configure XML sitemap and search engine crawler instructions, run automated smoke tests, and produce the Phase 3 verification report.

## Tasks

### Task 1: Assemble Complete Homepage (`src/app/[locale]/page.tsx`)
- Integrate sections in approved narrative sequence:
  1. `Header` (sticky frosted glass with logo, navigation, and language switch)
  2. `HeroSection` (cinematic headline, value proposition, CTAs, live capacity indicator, floating 3D phone mockup)
  3. `TrustStrip` (4 credibility markers)
  4. `ProblemSolutionSection` (Western apps vs FitKarma)
  5. `FeatureBentoGrid` (6 moats with 3D perspective frames and rollout badges)
  6. `NutritionShowcase` (household portions: katori, roti, tadka slider, family recipe splitter)
  7. `HowItWorksSection` (3-step verification walkthrough)
  8. Placeholder anchor for `#beta-card` (ready for Phase 5 registration card)
  9. `FaqAccordion` (10 expandable questions)
  10. `Footer` (brand info, sitemap, legal links, official support email)

### Task 2: Configure SEO Discovery Files (`src/app/sitemap.ts` & `src/app/robots.ts`)
- Create `src/app/sitemap.ts`:
  - Prerenders sitemap entries for root paths, `/en`, and `/hi` with alternate language links.
- Create `src/app/robots.ts`:
  - Disallows internal `/api/` and `/admin/` routes; allows public marketing routes; points to sitemap.

### Task 3: Create Automated Landing Page Smoke Test
- Create `tests/smoke/landing-page.test.ts`:
  - Test `features.ts` status consistency.
  - Test all section components export valid React elements.
  - Test that all 10 FAQ questions exist in both `en.json` and `hi.json`.
  - Test sitemap generator output structure.

### Task 4: Execute Quality Checks & State Update
- Run `node --test --import tsx tests/smoke/*.test.ts`.
- Run `pnpm type-check` and `pnpm lint`.
- Run `pnpm build` to verify Next.js production SSG output.
- Create `03-VERIFICATION.md` and update `.planning/STATE.md`.

## Acceptance Criteria
- [ ] Complete landing page renders cleanly in English (`/en`) and Hindi (`/hi`) with zero layout shifts.
- [ ] All sections render in the specified problem-first sequence.
- [ ] `sitemap.xml` and `robots.txt` generate valid output.
- [ ] Zero TypeScript or ESLint errors/warnings.
- [ ] `pnpm build` generates static HTML prerender for `/en` and `/hi`.
- [ ] `03-VERIFICATION.md` generated documenting proof of compliance.
